## تعليمات الاستخدام

### الوصول الى المقررات 

- افتح موقع الجامعة من [هنا](https://sso.iu.edu.sa/Account/Login)
- توجه الى اكاديمي > التسجيل الإلكتروني >  المقررات المطروحة وفق الخطة 

### صفحة بناء الجدول افترضي
- ستظهر واجهة "بناء الجدول" تلقائياً
- اضغط "عرض بناء الجدول"

### البحث والفلترة
- استخدم خانة البحث للبحث
- اختر نوع الفلتر: الكل / المقرر / الدكتور / الشعبة / اليوم / الوقت
- فعّل "إخفاء الشعب المغلقة" إذا أردت

### اختيار المقررات
- انقر على المقرر لإضافته للجدول
- الشعب المسجلة تُختار تلقائياً ✓
 <br>
   ملاحظة:
   اذا لم تظهر مقرراتك تلقائياً اذهب الى المقررات المسجلة وعد الى المقررات المطروحة وفق الخطة  


### فحص التعارضات
- اضغط " فحص التعارضات"
- التعارضات تظهر بوميض أحمر 


### نسخ وتحميل
- 📋 **نسخ أرقام الشعب:** ينسخ للحافظة
- 📥 **تحميل كصورة:** يحفظ الجدول كـ PNG



## ملاحظات مهمة

1 - الإضافة تعمل **فقط** على موقع الجامعة الإسلامية فقط.

2 - الاضافة عمال تطوعي **غير رسمية** تم انشائه لمساعده الطلاب في تنظيم وترتيب جدولهم.

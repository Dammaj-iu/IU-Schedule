## 📖 تعليمات الاستخدام

### 1️⃣ فتح بوابة الجامعة
اذهب إلى: `https://eduportal.iu.edu.sa`

### 2️⃣ صفحة الشعب المسجلة
- اذهب إلى صفحة "الشعب المسجلة"
- الإضافة ستحفظ شعبك تلقائياً

### 3️⃣ صفحة التسجيل
- اذهب إلى صفحة "التسجيل"
- ستظهر واجهة "بناء الجدول" تلقائياً
- اضغط "عرض بناء الجدول"

### 4️⃣ البحث والفلترة
- استخدم خانة البحث للبحث
- اختر نوع الفلتر: الكل / المقرر / الدكتور / الشعبة / اليوم / الوقت
- فعّل "إخفاء الشعب المغلقة" إذا أردت

### 5️⃣ اختيار المقررات
- انقر على المقرر لإضافته للجدول
- الشعب المسجلة تُختار تلقائياً ✓

### 6️⃣ فحص التعارضات
- اضغط "⚠️ فحص التعارضات"
- التعارضات تظهر بوميض أحمر 🔴

### 7️⃣ نسخ وتحميل
- 📋 **نسخ أرقام الشعب:** ينسخ للحافظة
- 📥 **تحميل كصورة:** يحفظ الجدول كـ PNG
